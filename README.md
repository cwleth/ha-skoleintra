# ha-skoleintra

Home Assistant add-on der henter ugeplanen fra ForældreIntra (SkoleIntra) ind i
Home Assistant via MQTT discovery. Kræver login med brugernavn og kode (ikke MitID).

Tilføj `https://github.com/cwleth/ha-skoleintra` som add-on-repository.
Se `skoleintra/README.md`.

Login-flowet bygger på [CavaleriDK/skoleintra](https://github.com/CavaleriDK/skoleintra) (MIT).
